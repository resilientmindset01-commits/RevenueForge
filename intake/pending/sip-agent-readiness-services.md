# Revenue-model seed: agent readiness as a service (agent mystery shopper + WebMCP conversion)

Source: The Startup Ideas Podcast (@startupideaspod, Greg Isenberg's show), episode "WebMCP clearly explained
(and how to make $$)", 2026-08-26, guest Vinny (@hot_town); and the account's X post of the same idea
(x.com/startupideaspod/status/2093371149694710151). Episode notes read on Apple Podcasts; the post read in full.
Prices are the source's UNVERIFIED claims. WebMCP facts are in claude-techniques agent-ready-codebase, checked
against the spec and Chrome's announcement. Scored for FIT against the operator's portfolio (PrepBrix NEET/JEE,
the forge skill pack, ng-monitor, tamiliq).

## Card 1 -- Agent mystery shopper (recurring audit)
Model: send an AI agent through a company's revenue journeys the way a customer would -- checkout, quote request,
booking, claim -- on a schedule, and report where it stopped: vague descriptions, missing tools, dead ends near
the conversion. The recurring report is the product (the source prices it at $100-300 a month per site). Once the
same failures repeat across many sites, build the fix into software and sell that too; the source's point is that
the software step only works after the audits have shown the pattern.

## Card 2 -- WebMCP conversion agency (the fix)
Model: sell the remedy the audit exposes -- add WebMCP tools (task-shaped, with consequential steps marked) so
agents can complete the journey. The audit makes this a warm sale: the client has already seen where the agent
gave up. First markets named in the episode: complex commerce, SaaS admin consoles, read-only flows in regulated
industries, internal tools.

## FIT
OFF-PORTFOLIO as a venture to launch: it is a services business for other companies' sites, and there is no
client base or delivery capacity. The standard is still a draft in an early preview, so a paid WebMCP practice
would be selling ahead of the market.
SELF-APPLICATION (the useful part): run the mystery-shopper test on the operator's own paid funnels -- the
tools.prepbrix.com landing page and the Gumroad pack pages. Can an agent find the product, understand what is
included, and reach checkout? The failures it logs are a cheap, concrete to-do list, and they matter more as
agents start doing purchases for people. No outcome recorded; the launch is held.
