## Why this matters to us
We sell Claude Code skills (paid pack + free 3-skill lead magnet). The megathread
shows (a) what pains people build for = validated demand next to our own pack, and
(b) new channels to reach those same builders.

## Validated demand clusters (ranked by how often it recurred)
1. SESSION MEMORY / CONTINUITY -- by far the most repeated pain. Many separate
   projects all rebuild the same thing: memory that survives across Claude Code
   sessions. Framings seen: "every session is a brilliant new hire with zero memory,"
   knowledge OS on Claude Code, persistent graph memory, shared memory layer across
   Claude/ChatGPT/Cursor via MCP, "flow" continuity, cold-start every session. This is
   the strongest product signal in the thread. Our pack does not cover it -- candidate
   for a next skill (a memory/handoff skill) or a paid add-on. Pairs with
   ConceptForge context-management handoff work.
2. CONTEXT + USAGE VISIBILITY -- track context left, usage-limit reset, and per-session
   cost. Several tools (context monitors, a "Claude Monitor" HQ, a session cost
   profiler that cut a session 60%). Signals people will pay attention to a
   cost/context skill (we have context-curation -- lead with the cost angle).
3. STOP HALLUCINATION / FAKE WORK -- a plugin that "stops Claude making things up,"
   a workflow to stop fake tests, humanizing AI writing. Overlaps our review-ai-code
   and adversarial-self-critique. Confirms the "agent quietly ships bad code" hook lands.
4. SESSION AUDIT / SAFETY RECEIPTS -- a tool that records each Claude Code session and
   emits a receipt with risk flags (touched auth files, ran rm -rf, read .env). Direct
   neighbor to our agent-bash-security skill; validates that shell-safety is a felt pain.
5. HOOKS ARE UNDERUSED -- a popular post argued Claude Code Hooks are "criminally
   underused." A hooks-focused skill or writeup has an audience.

## Marketing tactic worth stealing
GAP-FILL CONTENT: one builder took an official Anthropic webinar (20k lawyers, 51
audience questions, only ~half answered live), transcribed it, pulled the unanswered
questions, and built + published a skill answering the gap. Pattern: find an official
Anthropic resource's unanswered questions or missing pieces, fill them, publish. High
authority, low slop, and it rides existing search/interest. Candidate content play for
our distribution lane (pairs with geo-distribution).
